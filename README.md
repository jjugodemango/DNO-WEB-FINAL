## 2. ¿Con qué?

### Bases de datos a utilizar

* Base de datos de Farmacias en Chile (MINSAL), que incluye:

  * Nombre de farmacia.
  * Región.
  * Comuna.
  * Dirección.
  * Horario de apertura y cierre.
  * Coordenadas geográficas (latitud y longitud).
  * Estado de turno.
  * Fecha de funcionamiento.

json se encontrará adjunto en este repositorio

## 3. ¿Qué?

### Dashboard Interactivo de Cobertura Farmacéutica en Chile

Un dashboard interactivo orientado a visualizar la distribución territorial de farmacias en Chile y facilitar la búsqueda de servicios farmacéuticos.

El sistema permitirá explorar:

* Distribución de farmacias por región y comuna.
* Mapa interactivo con geolocalización.
* Farmacias de turno disponibles.
* Horarios de funcionamiento.
* Comparación territorial de cobertura farmacéutica.
* Concentración de cadenas farmacéuticas.
* Indicadores de acceso a servicios de salud.

### Objetivo

Facilitar el acceso ciudadano a información farmacéutica y generar una herramienta de análisis territorial para investigadores, organismos públicos y usuarios comunes.
